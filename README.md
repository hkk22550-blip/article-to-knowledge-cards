# make-knowledge-cards

## 1. 项目解决什么问题

读文章时经常遇到两个问题：一是读完抓不住重点，二是过几天就忘。这个 Skill 把长文章自动拆解成结构化知识卡片，帮你快速提炼核心知识点，并用自测问题强化记忆。

它解决的核心痛点：
- **信息过载**：一篇长文章读完记不住几条关键内容
- **重复冗余**：原文中反复强调的内容，提炼时自动去重
- **强行凑数**：不会为了凑数量把次要信息也做成卡片，知识点少就少出几张

## 2. 主要功能

- 将用户粘贴的文章或本地 Markdown/TXT 文件转换为 **5～8 张知识卡片**
- 每张卡片包含四个部分：**标题、核心知识、简明解释、例子或自测问题**
- 一张卡片只讲一个独立知识点，自动合并重复内容
- **不编造**：所有内容严格来自原文，不补充外部知识
- **不凑数**：原文知识点少就少出几张，不会硬撑到 5 张
- 纯文本输出，无脚本依赖

**暂不支持**：网页抓取、PDF 解析、Anki 导出、图形界面卡片

## 3. 安装方法

这是一个纯指令型 Skill，没有脚本依赖。

```bash
# 把 skill 目录复制到你的 skills 文件夹下
cp -r skills/make-knowledge-cards /your/skills/path/
```

目录结构：

```
make-knowledge-cards/
├── SKILL.md           # Skill 核心指令（必需）
└── agents/
    └── openai.yaml    # Agent 界面配置
```

无需安装任何依赖包，直接放入 Skill 目录即可被识别。

## 4. 使用方法

### 输入方式

**方式一：直接粘贴文本**
在对话中把文章内容发给助手，并说明要做知识卡片：

> 帮我把这篇文章做成知识卡片：[粘贴文章内容]

**方式二：提供本地文件**
给出 `.md` 或 `.txt` 文件的路径：

> 把 `notes/sleep-science.md` 做成知识卡片

### 输出格式

每张卡片按以下结构输出：

```
### 卡片 N：标题

**核心知识：** 一句话陈述这个知识点

**解释：**
2～4 句话的简明说明

**例子 / 自测：**
一个具体例子或一道自测问题
```

### 质量规则

- 所有内容必须来自原文，不能编造
- 一张卡片只讲一个知识点，互不重复
- 信息不足时宁可少出，不强行凑数
- 解释部分用短句，避免学术化堆砌

## 5. 输入输出示例

### 输入示例

用户粘贴一段关于费曼学习法的文字：

> 费曼学习法的核心很简单：如果你不能用简单的话把一个概念讲给别人听，说明你还没有真正理解它。具体做法分四步：选择一个概念、向别人讲解、找出卡壳的地方回去补、然后用更简洁的语言重新讲一遍。这个方法之所以有效，是因为"讲出来"会逼你把脑子里模糊的理解变成清晰的逻辑。卡壳的地方就是你知识的盲区。

### 输出示例

> 本文核心知识点较少，共提取 2 张卡片。

**### 卡片 1：费曼学习法核心**

- **核心知识：** 不能用简单的话把概念讲给别人听，就说明还没有真正理解
- **解释：** "讲出来"会逼你把模糊的理解变成清晰的逻辑。核心不是教别人，而是通过输出暴露知识盲区。
- **自测：** 如果你学了一个概念但讲不清楚，问题出在理解还是表达？

**### 卡片 2：费曼四步法**

- **核心知识：** 选概念 → 讲给别人听 → 找出卡壳处回去补 → 用更简洁的语言重讲
- **解释：** 卡壳的地方就是知识的盲区，补完之后再用通俗的话重讲一遍，直到顺畅为止。
- **例子：** 学完一个知识点后，讲给完全不懂的人听，哪里卡住就回去补哪里。
