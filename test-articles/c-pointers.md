# C 语言指针入门

指针是 C 语言中最重要也最容易混淆的概念。要理解指针，先记住两个核心概念：内存地址和指针变量。

## 什么是指针

每个变量在内存中都占用一块空间，这块空间有一个编号，就是内存地址。指针变量是一种特殊的变量，它存储的不是普通数据，而是另一个变量的内存地址。通过这个地址，你可以间接访问或修改那个变量的值。

## 取地址与解引用

`&` 运算符用来取变量的地址，`*` 运算符用来解引用——也就是从地址取出对应的值。例如 `int a = 10; int *p = &a;` 之后，`*p` 就等于 `a` 的值 10，修改 `*p = 20` 会直接改变 `a` 的值。

## 指针与数组的关系

数组名本质上是数组首元素的地址。所以 `arr[i]` 等价于 `*(arr + i)`。这意味着可以用指针遍历数组，而且指针运算比数组下标写法更灵活。需要注意的是，数组名是常量地址，不能对它赋值，例如 `arr++` 是非法的。

## 函数参数传递

C 语言的函数参数都是值传递——传入的是副本。如果想在函数内部修改外部变量，必须传递该变量的指针。比如交换两个变量的值，必须传入两个指针，否则函数内交换的只是副本，外部变量不会变。

## 常见错误

未初始化的指针（野指针）指向随机内存，访问它会导致程序崩溃。指针释放后继续使用（悬空指针）也会出问题。用完指针后置空是一个好习惯。
